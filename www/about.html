About

webserv is a single-threaded, non-blocking HTTP/1.1 server. All socket and CGI pipe I/O is driven by a single poll() call in the main event loop.

Features

  • GET, POST and DELETE
  • Virtual hosts on a shared interface:port
  • CGI execution (Python) for GET and POST
  • File uploads, including multipart/form-data
  • Directory listing, custom error pages, HTTP redirects
  • Per-server and per-location body size limits
